# JD Bean Sign

轻量级京东每日签到管理工具。范围仅限每日签到、签到领京豆，不包含农场、宠汪汪、种豆得豆、金融任务、店铺任务、浏览任务、抽奖或助力。

> 早期开发版本。京东登录与签到接口可能变化，请先用测试账号验证。当前 Web 管理端尚未提供登录认证，不要直接暴露到公网。

## 已实现

- Docker / Docker Compose 部署骨架
- 中文 Web 仪表盘
- 多账号添加、启用、停用、删除
- Cookie Fernet 加密存储，密钥保存在持久化目录
- 京东 App 扫码登录：二维码生成、扫码状态轮询、ticket 校验、自动提取 pt_key / pt_pin
- 相同 pt_pin 再次扫码时更新原账号 Cookie
- Cookie 登录态检测
- 单账号 / 全部账号手动签到入口
- 每日定时任务（默认容器时区 08:05）
- 签到记录与京豆统计框架
- GitHub Actions 多架构 Docker 镜像构建配置

## 尚待完成 / 验证

- 京东签到业务接口需要用真实账号完成端到端适配；未知业务响应会记为接口异常，不会将 HTTP 200 误判为成功
- 京东扫码登录需要真实账号端到端验证，Passport 接口可能因平台调整或风控变化而失效
- 管理端登录认证、CSRF 防护、Cookie 更新页面、自定义签到时间
- 镜像发布结果与 amd64 / arm64 实机验证

## 启动

```bash
git clone https://github.com/ztesfyfi/JD-Bean-Sign.git
cd JD-Bean-Sign
docker compose up -d --build
```

浏览器打开 `http://服务器IP:8080`。数据保存在当前目录 `./data`，请备份整个目录。丢失 `data/secret.key` 将无法解密已保存的 Cookie。

## 扫码登录

在管理页点击“京东 App 扫码登录”，使用京东 App 扫码并在手机上确认。服务端轮询京东 Passport 状态，校验 ticket 后提取登录 Cookie，并执行登录态检测；检测通过后自动加密保存。相同 `pt_pin` 再次扫码会更新原账号 Cookie。二维码会话约 3 分钟过期，可点击刷新重新获取。

也可展开“手动添加 Cookie”作为备用方式。Cookie 属于敏感凭据，请勿截图、公开分享或提交到 Git。

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DATA_DIR` | `/data` | 数据目录 |
| `TZ` | `Asia/Shanghai` | 容器时区 |
| `SIGN_TIME` | `08:05` | 每日自动签到时间，24 小时制 |

## 安全提醒

当前版本没有管理端登录系统，仅适合可信的本机或内网环境。公网部署前必须先加入身份认证、HTTPS 和访问控制。不要在 Issue、日志或聊天中发送真实 Cookie、二维码登录会话 ID 或账号凭据。
